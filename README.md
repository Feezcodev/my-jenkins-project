# My Jenkins CI/CD Pipeline Project

A robust CI/CD pipeline project utilizing a declarative `Jenkinsfile` running within a containerized environment (WSL2/Docker & Jenkins).

## 🚀 Project Overview
This project demonstrates Pipeline-as-Code principles using Jenkins. The build configuration pulls code directly from GitHub via SCM and executes a structured pipeline.

* **Repository:** `https://github.com/Feezcodev/my-jenkins-project`
* **Branch:** `main`
* **Orchestration Tool:** Jenkins CI

## 🛠️ Tech Stack
* **Environment:** Windows Subsystem for Linux (WSL2 / Ubuntu)
* **Containerization:** Docker & Docker Compose
* **CI/CD Server:** Jenkins (Pipeline-as-Code)
* **Version Control:** Git & GitHub

## 📋 Pipeline Architecture
The pipeline is defined declaratively using a `Jenkinsfile` inside the repository root. It handles automated checkout, execution phases, and verification.

## 📊 Validation & Execution
Successfully verified and executed using Jenkins Pipeline SCM configuration with green-status build completion.
